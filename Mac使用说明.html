Mac 使用说明 · v5.4

推荐用 start_mac.pyw 打开银行流水合并工具。这份说明可离线阅读，下载 Python 和查看测试记录时才需要联网。

按这四步操作

  1. 安装 Python，解压完整工具。
    下载并安装官方 Python 3.13.17 Mac 安装包，内含 PythonLauncher 和 tkinter。解压完整的工具文件夹；start_mac.pyw、bank_merge.py、其他程序文件和 vendor 要放在一起。
  2. 先设置一次 PythonLauncher。
    在 Finder 打开 应用程序 → Python 3.13 → PythonLauncher 本身，先不要打开脚本。名称也可能显示为 Python Launcher。打开 Preferences（偏好设置），文件类型选 Python Script，取消勾选 Terminal 窗口选项（Run in a Terminal window）。关闭偏好设置，再退出 PythonLauncher 保存设置。这也会影响它打开的其他同类脚本。
  3. 打开 start_mac.pyw。
    回到工具文件夹，右键 start_mac.pyw，选 打开方式 → PythonLauncher。若没有列出，选 其他…，到 应用程序 → Python 3.13 中选择。若出现文件类型或默认打开程序的提醒，点 OK；本次实测中这是普通提醒，之后显示银行工具窗口。
  4. 以后这样使用。
    以后按相同方式打开。也可选中文件，在 显示简介 → 打开方式 中选 PythonLauncher，记住打开程序。进入工具后，选择原始流水，查看格式检查，再点击“校验并生成”。陌生表头可用“设置列对应”；“支持范围”可离线查看格式和限制。

旧的 start_mac.command 仍保留，但某些下载副本可能继续被阻止。请使用 start_mac.pyw。复制、移动或发给同事时，请保留完整工具文件夹。

IQ 输出规则

表头 → 月初日期 → 所有交易 → 月末日期。首尾日期行的其余六列留空，不计入笔数和金额。金额正负号、内部转账和疑似重复交易均保留；缺少完整期初期末余额时会明确提示。QIF 的日期设置单独默认为 AUTO；FNB 官方 QIF 使用 MDY，需核对来源后再选择。

实测到了哪一步？

Mac 原生启动实测 40195756629 使用 Python 3.13.17，关闭了 Terminal 启动选项。在无隔离属性、人工设置 0083 和人工设置 0087 三种情况下，都显示银行工具窗口，出现普通文件类型提醒，未出现“已损坏”提示。

默认设置实验 40195406500 停在 macOS 请求控制 Terminal 的权限提示，因此采用上面的普通偏好设置启动。
